# Architecture Decision Records

This directory holds ADRs — short records of a significant architectural or technical
decision: what was decided, why, and what alternatives were considered. One file per
decision, named `NNNN-short-title.md` (zero-padded, sequential), never edited after the
fact — a changed decision gets a new ADR that supersedes the old one.

No ADRs have been recorded here yet. Add one the next time a decision worth remembering
gets made (the `domain-modeling` skill supports drafting them) rather than back-filling
history that wasn't captured at the time.
